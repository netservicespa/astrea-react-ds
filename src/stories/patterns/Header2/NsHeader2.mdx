<h3>Customizzazione</h3>
{/* <Controls of={NsHeader2.AdvancedExample}/> */}

Per la customizzazione dell'header è necessario passare come children `NsHeaderBox` e 
specificare `nsPosition` per ogni componente.

```jsx
// Esempio di `nsPosition`:
nsPosition={{
                desktop: { level: NsHeaderLevel.MAIN_BAR, position: 'center' },
                mobile: { level: -1, position: 'left' },
              }}
```
All'interno di `NsHeaderBox` è possibile inserire qualsiasi componente.
<br/>
Per semplificare la creazione di header complessi, sono stati creati i seguenti componenti:
- `NsHeaderBox`
- `NsHeaderHambuger`
- `NsHeaderLogo`
- `NsHeaderMenu`
- `NsHeaderNotification`
- `NsHeaderUserMenu`
